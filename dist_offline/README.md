# Офлайн-дистрибутив

Здесь появятся скрипты и инструкция для сборки портативного дистрибутива (этап 7):
embeddable Python 3.8.10 x64, wheel-файлы из `requirements.txt` для `cp38-win_amd64`,
файлы tkinter и код приложения.

Скачанные файлы (`wheels/`, `python/`, `build/`, `*.zip`) в git не попадают.
