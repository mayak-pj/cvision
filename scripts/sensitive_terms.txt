# Слова-маркеры для scripts/check_before_push.py: если такое слово встретится
# в файлах репозитория или в сообщениях коммитов, проверка сообщит об этом.
#
# ЭТОТ ФАЙЛ ПУБЛИКУЕТСЯ. Не пишите в него реальные названия: сам список
# конфиденциальных слов тоже является утечкой.
#
# Реальные термины держите в файле scripts/sensitive_terms.local.txt —
# он не версионируется (правило *.local.txt в .gitignore).
# Формат обоих файлов одинаков: одно слово или словосочетание в строке,
# регистр не важен, строки с «#» — комментарии.
#
# Что обычно стоит туда внести:
#   - название компании, отдела, заказчика;
#   - названия изделий и внутренние обозначения;
#   - имена серверов и сетевых папок;
#   - фамилии сотрудников;
#   - номера договоров и заказов.
#
# Пример (замените своими и перенесите в sensitive_terms.local.txt):
# ООО Ромашка
# Изделие А-123
# fileserver01
